# Sea Level Predictor

## Project Overview

This project is part of the freeCodeCamp Data Analysis with Python Certification.

The objective of this project is to analyze historical global sea level data and predict future sea level rise through the year 2050 using linear regression.

The project uses data visualization and statistical analysis techniques to identify long-term trends in sea level changes.

## Features

- Load and analyze historical sea level data
- Create a scatter plot of sea level measurements
- Generate a line of best fit using all available data
- Generate a second line of best fit using data from the year 2000 onward
- Predict sea level rise through the year 2050
- Visualize trends using Matplotlib

## Dataset

The dataset contains global average sea level measurements collected from 1880 to 2014.

Source:
- US Environmental Protection Agency (EPA)
- Commonwealth Scientific and Industrial Research Organisation (CSIRO)

## Technologies Used

- Python
- Pandas
- Matplotlib
- SciPy
